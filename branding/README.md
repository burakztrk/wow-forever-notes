# Forever Codex — brand

Name and icon for the mobile app (and the site favicon). Original artwork:
no Blizzard logos, icons or art.

| | |
|---|---|
| App name | **Forever Codex** |
| Store title (≤30) | Forever Codex: Talent Planner |
| iOS subtitle (≤30) | Patch notes & talent builds |
| Short description (Play, ≤80) | Unofficial WoW Forever companion: patch notes, talents, races, classes. |
| Package / bundle id | `com.booapps.forevercodex` |
| Colours | background `#131620`, gold `#c8a656`, page `#f1d896`, text `#e8e2d0` |

**Why not "WoW …" in the name:** "WoW", "Warcraft" and "World of Warcraft" are
Blizzard trademarks (Apple 5.2.1, Google Play impersonation policy). The game is
named only descriptively in the store text, together with:

> Unofficial fan-made companion. Not affiliated with or endorsed by Blizzard
> Entertainment. World of Warcraft and related names are trademarks of
> Blizzard Entertainment, Inc.

"Forever Notes" was rejected: it collides with the known *Forever ✱ Notes*
note-taking method for Apple Notes.
